# Lucky Lobby

Fabric 1.20.1 用Mod(専用サーバー/シングルプレイ(統合サーバー)の両対応)。ロビーから **ラッキーワンブロック / ラッキーブロックPVP / ラッキー一本道レース** を選んで遊べます。
ゲーム用ワールドは [Fantasy](https://github.com/NucleoidMC/fantasy) で開始時に生成され、終了時に削除されます。クライアントMod不要(チェストGUI)。
ロビーにはスロット・ブラックジャック・ビデオポーカーがあり、待ち時間に遊べます。

## 必要なもの
- Minecraft 1.20.1 / Fabric Loader / Fabric API / Java 17
- [Lucky Block Mod](https://luckyblockmod.com/) の **1.20.1 版 Fabric jar** をサーバーに導入
- 本Modのjar(Fantasyはjar内に同梱)

## ビルド
- GitHub Actions: push すると自動ビルドされ、Artifacts から jar を取得できます
- ローカル: `gradle wrapper` → `./gradlew build` → `build/libs/luckylobby-*.jar`
- `gradle.properties` の `fantasy_version` は https://maven.nucleoid.xyz/xyz/nucleoid/fantasy/ で 1.20.1 対応版を確認してください

## 遊び方
- 参加するとロビーへ。ホットバー: コンパス=管理メニュー(OP/ホスト) / エメラルド=カジノ
- ロビーのブロック: 金=スロット / エメラルド=ブラックジャック / ラピス=ポーカー / ビーコン=管理コンソール(OP)
- 管理メニューでモード・チーム・各種設定を選び「スタート」
- コマンド: `/lucky menu | casino [slot|blackjack|poker] | coins [give <player> <n>] | lobby | stop`

## モード
| モード | 内容 | ロビーで設定できる項目 |
|---|---|---|
| ラッキーワンブロック | 空の世界の1ブロックを壊し続ける(壊すと即再生成)。ラッキーブロックから出る**エンドポータルフレーム/エンダーアイ**で通常のポータルを作り、本物のエンドへ入って**エンダードラゴンを討伐するとクリア**。ドラゴン戦はワールド共通のため、討伐後は**新しいワールドを作り直して**遊ぶ(討伐済みワールドでは開始不可) | なし |
| ラッキーブロックPVP | 正方形アリーナで個人戦/チーム戦。脱落者は観戦、最後の1人(1チーム)が勝利。時間切れは最多キル | チーム数、**初期配布ラッキーブロック数**、制限時間、プレイヤー別チーム/観戦 |
| ラッキー一本道レース | **空中に浮く幅1マスの一本道**をレーンごとに敷き、道を**ラッキーブロックの壁が塞ぐ**。壊して進みゴールを目指す。**レーン間のすき間は1マス。自レーンから2マス近く離れる(隣レーンへ移る)と即死、落下も即死**。落ちたら最後に通過した壁の先から再開。制限時間・順位・ランダムイベントあり | コース長、壁の間隔、曲がり角、制限時間、イベントON/OFF |

## カジノ(コインはワールドに永続)
スロット / ブラックジャック(BJ x2.5, ダブルダウン) / ビデオポーカー(ジャックス・オア・ベター)。初期1000コイン、尽きると500救済。

## 既知の注意点
- 未実機テストです。`VoidChunkGenerator` / Fantasy API / `Text.Serializer` はバージョン差でコンパイルエラーになる可能性があります。
- ドラゴン戦はワールド共通の本物のエンドで行います。討伐後は新しいワールドを作り直してください。
- シングルプレイでは、ワールドのホストが自動的に管理者として扱われます。
