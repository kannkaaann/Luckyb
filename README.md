# Lucky Lobby

Fabric 1.20.1 用Mod(専用サーバー/シングルプレイの両対応)。ロビーから **ラッキーワンブロック / ラッキーブロックPVP / ラッキー一本道レース** を選んで遊べます。
ゲーム用ワールドは [Fantasy](https://github.com/NucleoidMC/fantasy) で開始時に生成され、終了時に削除されます。
**操作はすべてロビー内のボタン・床・空中の表示で行い、インベントリ(持ち物/チェスト画面)は使いません。**

## 必要なもの
- Minecraft 1.20.1 / Fabric Loader / Fabric API / Java 17
- [Lucky Block Mod](https://luckyblockmod.com/) の **1.20.1 版 Fabric jar**
- 本Modのjar(Fantasyはjar内に同梱)

## ビルド
GitHub に push すると Actions が自動ビルドします(Java 21 + Gradle 9.2.1 + Loom 1.14.10)。`build/libs/luckylobby-*.jar` が成果物です。
`fantasy_version` は `0.4.11+1.20-rc1` 固定です(1.20系で公開されている唯一の版で、1.20.1でも動作します)。

## ロビーの使い方(すべてボタン)
ワールドに入るとロビー(円形の広場)へ移動します。ボタンは石のボタン(カラーブロックの台座つき)で、クリックすると反応します。

### 北側: 管理コンソール(OP / シングルプレイのホスト専用)
1. **モード選択**(奥の列): ワンブロック / PVP / レース
2. **設定ボタン**(中の列): モードに応じて項目が変わる。クリックで値が切り替わる
   - PVP: チーム設定 / 初期ラッキーブロック数 / 制限時間
   - レース: チーム設定 / コース長 / 壁の間隔 / 曲がり角 / 制限時間 / ランダムイベント
3. **▶ スタート**(緑) / **■ ゲーム強制終了**(赤)

### チーム選択(床)
色つきの床に**乗ったチームで参加**します(PVP・レースでチーム戦のとき)。
赤・青・緑・黄 / 灰色=観戦 / 白=おまかせ(ランダム)。各床の上に人数が表示されます。

### 南側: カジノ
コインは最初1000枚(尽きると500枚補充)。ワールドに保存されます。
- 左奥 **スロット**: ベット−/＋、金ブロックの **SPIN**
- 正面 **ブラックジャック**: ベット−/＋、DEAL / HIT / STAND / DOUBLE
- 右奥 **ビデオポーカー**: カードの下の **HOLD** ボタンで残すカードを選び、DEAL → DRAW
- 手前の金ブロック: 所持コイン確認

## モード
| モード | 内容 |
|---|---|
| ラッキーワンブロック | 空の世界の1ブロックを壊し続ける(壊すと即再生成)。ラッキーブロックから出る**エンドポータルフレーム/エンダーアイ**で通常のポータルを作り、そのワールドのエンドへ入って**エンダードラゴンを討伐するとクリア**。討伐済みのワールドでは開始できないので、新しいワールドで遊び直す |
| ラッキーブロックPVP | 61×61の壁つきアリーナで個人戦/チーム戦。死んだら観戦。最後の1人(1チーム)が勝ち。時間切れは最多キル |
| ラッキー一本道レース | **空中の幅1マスの一本道**を、ラッキーブロックの壁(幅3×高さ2)が塞ぐ。レーン間のすき間は1マス。**道の真上(高さ3マス目)はバリアで塞がれ、ブロックを積んで越えられない**。ラッキーブロックで道の地面が壊れても**すぐ張り直される**。**死んだら最初から**(スタートへ戻り、壁も全て新品になる)。隣のレーンへ移る(約2マス離れる)/落下で即死 |

## コマンド(補助)
`/lucky coins` / `/lucky coins give <player> <n>`(管理者) / `/lucky lobby` / `/lucky stop`(管理者) / `/lucky rebuild`(管理者: ロビーを作り直す)

## 既知の注意点
- 実機での動作確認前の版です。
- ドラゴン戦はワールド共通の本物のエンドで行います。
- シングルプレイでは、ワールドのホストが自動的に管理者として扱われます。
- 空中表示(文字・アイテム)はディスプレイエンティティを使うため、Minecraft 1.19.4以降が必要です(1.20.1はOK)。
